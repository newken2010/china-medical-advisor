# 疾病 × 流向 渠道矩阵（稳定项）

> 回答「我得 X 病，我该走什么渠道、去哪个方向、大概什么量级、坑在哪」——**只给渠道结构与决策点，不推荐具体机构/医院，不替用户做医疗决定**。
> 数字纪律：只引用 `medical-prices.json` 已核条目的量级；没核到的写「缺口」，不编、不估。成本量级列里标〔A/B/C〕是数据分级。
> 本矩阵是**稳定项**（渠道结构短期不变）；具体机构的资质/价格/电话是**时效项**，走实时核对。

## 〇、先问三个分诊问题（决定走哪一栏）

1. **人在哪 / 国籍？**（中国人 / 外国人在华 / 海外华人）→ 决定「流向」
2. **什么病 / 什么阶段？**（初诊求方案 / 标准治疗做不了 / 要新药临床试验 / 择期手术）→ 决定「病种行」
3. **预算什么量级？**（决定「去哪个国家」时先看目的地成本列，再看病种匹配）

## 二、机构选择中立框架（只给框架，不点名推荐）

> 用户问「找什么机构/怎么不被坑」时按此答。这是**裁判位，不是参赛位**——我们不接活、不导流、不返佣。

### 四类模式（买什么先看清）

| 模式 | 你付的钱买的是 | 适合 | 不适合 |
|---|---|---|---|
| 医院驻华代表处/国际部 | 医院这一段的直连（无加价） | 已确定医院、只需预约 | 需要签证/行程/陪诊全套 |
| 重资产全流程机构 | 全链条人力（翻译/预约/签证/陪诊）+ 医院折扣 | 重症、复杂、要兜底 | 预算紧（服务费 10 万级，美联医邦科普文口径 2026-08-24，C 级） |
| 信息平台型 | 信息与对接，落地自行或另购单项 | 自己拿主意、只要信息透明 | 要全程陪伴 |
| 个人工作室 | 最便宜的转手 | 已定目标医院、只需零星协助 | 完整托付（环节不可控） |

### 四查（签约前）

1. **社保参保人数**（0 人=空壳风险，「天眼」类公开工商信息可查——公开信息，非本技能代查）
2. **合作医院官网列名**（签约是真是假，医院官网/国际部页面可核验）
3. **团队资质**（医学背景占比、翻译资质，要看到人看到证）
4. **退款条款**（冷静期时长、已发生费用怎么算，盛诺 48 小时冷静期+5 万违约赔付是行业公开标杆——引用作「有退款承诺的长这样」，不是推荐）

### 行业红线（遇到直接 pass，写在合同前）

- 承诺疗效 / 「包成功」/ 「保证批下来」→ 任何国家的医疗法规都不保护这种对赌
- 治疗费经手加价且拒绝直付医院 → 费用不透明
- 「绿色通道」实为普通预约且事前不书面说明 → 虚假资源
- 诱导放弃国内可做的标准治疗 → 利益冲突信号

## 四、红线（与 SKILL.md 一致，渠道咨询同样适用）

1. 器官移植/代孕/管制药品 → 「不可行且违法」，停，不展开不指路。
2. 不推荐具体医院/机构排名，不承诺签证/审批/疗效。
3. 急性病 → 先就近急救，跨境决策放在急性期之后（这是安全红线，不是流程偏好）。
4. 数字未核到 = 说「缺口」，不给量级、不给「大概」。
