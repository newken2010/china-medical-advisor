# 中国就医流程指南（面向海外用户）

> 分两类：**稳定项**（流程结构，按此回答）与**时效项**（政策/机构细节，快照不可靠——用宿主 agent 联网搜索实时核对，或直说「以官方最新公告为准」）。
> 本指南不给医疗建议、不推荐具体医院、不代办。
> 渠道类问题（「我得 X 病走什么渠道 / 怎么选机构 / 去哪个国家」）见同目录 `channels.md`。

## 一、稳定项

### 1. 渠道结构
- 外籍患者的主流渠道是**公立三甲医院的国际医疗部 / 国际门诊**：独立诊区、通常有英语服务、价格明显高于普通门诊（普通门诊执行政府指导价，国际部多为自主定价）。
- 部分大型医院与境外商业医疗保险有**直付协议**（保险直接和医院结算）——具体哪些医院、哪些保险公司，属于时效项。
- 公立医院参与国家集采（VBP）的**承诺机构**执行集采价；民营机构可自主定价（种植类除外：2023-05 起承诺参与价格治理的民营机构也须执行官方结构价）。

### 2. 挂号与就诊
- 外籍人员凭**护照**（及有效签证/居留许可）在窗口或国际部前台挂号；线上渠道（医院官方 App / 微信 / 支付宝小程序）多数绑定中国手机号，外籍常用**现场/国际部电话预约**。
- 建议就诊前向国际部索取**费用预估（estimate）**：中国公立医院费用 = 挂号费 + 诊查/检查/检验 + 治疗/手术/住院 + 药品耗材，各项单列，可要求书面费用清单。
- 集采价（种植、支架、关节假体）适用于承诺参与的公立医院；做之前直接问「是否使用集采中选产品」即可锁定耗材价。

### 3. 支付
- 主流：**支付宝 / 微信支付**（近年已支持绑定多数境外发行的银行卡，支持范围与限额随时在扩——属时效项）、现金人民币、国际卡（部分医院 POS 支持，覆盖面有限——时效项）。
- 保险：中国**基本医保只覆盖参保人员**，外国人默认自费；境外商业保险是否可直付/报销，以保险合同约定为准。

### 4. 语言与陪同
- 国际部通常配备英语医生或翻译；普通门诊建议带翻译（手机翻译 App 可应付多数场景）。
- 病历/检查报告建议提前准备中英文版本（若从本国带既往资料）。

### 5. 周期与随访（实务提示，不是政策）
- 需要长周期治疗（如辅助生殖多周期、肿瘤治疗）的，通常要按治疗周期安排多次入境或办停留延期（延期属时效项）。
- 出院后的随访：部分医院支持电话/线上随访（覆盖范围因院而异——时效项）；也可回国后按方案复诊。

### 6. 明确限制（红线，直接拒绝）
- **器官移植**：中国器官分配通过国家统一系统（COTRS）向**中国公民受者**分配，不存在向外国人提供移植的正常渠道；「移植旅游」在中国**违法**。问到此 → 直接说明不可行，不展开、不指路。
- **血液/器官相关的灰色中介**：任何声称可代办「移植名额/供体」的中介均为诈骗或非法，提醒用户远离。

## 二、时效项（快照不答，实时核对或转官方）

| 条目 | 为什么必须实时 | 核对去向 |
|---|---|---|
| 签证类别与入境停留延期细节 | 政策随年份调整 | 中国使领馆官网 / 国家移民管理局（联网搜最新公告，带日期转述） |
| 具体医院国际部：是否接收外国人、收费标准、直付保险名单 | 院际差异大且随时变 | 目标医院官网/国际部（联网搜英文官网页） |
| 境外银行卡支付支持范围 | 支付渠道每季度在扩 | 支付宝/微信支付境外用户指引（联网搜） |
| 带药出入境规定（处方药数量/管制药品） | 海关规定调整 | 海关总署/目的国海关（联网搜，双侧都要查） |
| 医保政策（辅助生殖入医保的城市名单等） | 2024 起上海入医保，其他城市动态推进 | 国家医保局/当地医保局官网（联网搜） |

## 三、回答模板（流程类问题）

1. **先给流程主干**（按稳定项 2-3-4 条）：渠道 → 挂号（护照）→ 费用预估 → 支付 → 随访安排。
2. **标时效项**：「签证/某医院细节以官方最新为准」，用户要确定的话 → 走实时核对。
3. **成本锚点**：流程里自然带出对应术式的价差表条目（`medical-prices.json`），口径对齐规则见 SKILL.md。
4. **红线检查**：涉及器官移植、代孕、管制药品 → 直接答不可行 + 违法，停。
