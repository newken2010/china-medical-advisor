# china-medical-advisor — 中国就医价格与流程顾问（Agent Skill）

回答三类问题：
1. **中美价差**：「在中国做 X 多少钱」——辅助生殖（IVF）/ 种植牙 / 冠脉支架 / 髋膝关节置换 / 白内障 / ICL 近视矫正 / 癌症整病费用（NCI 官方 + 国家医保局 6 真实案例）/ LASIK 近视激光 / 体检套餐，9 个术式，每条带口径标签 + 来源（作者/日期/URL）+ A/B/C 分级
2. **疾病×流向渠道**：「我得 X 病走什么渠道」——6 病种 × 3 流向（中国人→海外 / 外国人→中国 / 海外华人→回国）渠道矩阵 + 机构选择中立框架（四查/红线，不点名推荐）+ 中美英日印目的地对照（`guide/channels.md`）
3. **就医流程**：「外国人怎么在中国看病」——渠道结构 / 挂号 / 支付 / 语言 / 随访安排
4. **限制项**：哪些事在中国做不了或违法（器官移植旅游等），直接答、不指路

**纯本地查表**：`medical-prices.json` + `guide/visit-guide.md` 随包分发，零服务器、零 API key、零成本。

## 数据质量分级

- **A 级**：官方源（国家医保局集采公告、上海市医保局接续采购文件等，已逐条直连核原文）
- **B 级**：权威媒体或多源一致（SART 全国报告、AAID、578 家医院 self-pay 等）
- **C 级**：单源，回答时必须标「单源，待复核」

**口径纪律**：中国「耗材集采价」≠ 美国「整台手术 Medicare 支付」，禁止跨口径直接相除出「差 N 倍」的假结论；对不齐就并列展示各自标口径。

## 红线（写进 SKILL.md，装了就生效）

- 不诊断、不推荐具体医院排名、不承诺疗效与审批
- 不接单、不导流、不返佣
- 器官移植 / 代孕 / 管制药品 → 答「不可行且违法」，停
- 中国基本医保只覆盖参保人，外国人按自费口径报价

## 数据更新
